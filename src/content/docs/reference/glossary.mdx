Every term below is defined the way this dossier uses it, India-contextual, not abstract. Two vocabularies meet here: the regulatory and finance set that decides whether the product is legal and sells (GST, ITC, PA/PPI, penny-drop), and the v2 product set that did not exist in v1 (credits, soft paywall, the capture pipeline, the PWA delivery ladder). Card-era and vendor-flow terms from v1 are pruned; vendor tax terms (TDS, RCM, MSME clock) stay because Phase 2 needs them. Canonical figures live in the thesis and in [/strategy/pricing/](/strategy/pricing/).

:::danger[The one row that defines the whole product]
Funds must never touch an account this SaaS owns or controls. The moment they do, RBI Payment Aggregator or PPI authorisation applies (PA net worth ₹15 cr at application, ₹25 cr by year 3). The file hand-off, customer-bank-execution payout model needs no authorisation [confirmed, high]. Full reasoning at [/compliance/money-movement/](/compliance/money-movement/).
:::

## Terms A to Z

| Term | Definition |
| --- | --- |
| auto-top-up | Optional setting that buys a credit pack automatically near zero balance, bounded by a monthly spend cap, with receipts and one-click off. Opt-in only. |
| `awaiting_credits` | The Claim.status entered when a claim is submitted at company credit balance 0. The claim is safe, visible, and queued; a top-up drains the queue FIFO. See [/phase-1/credits-and-metering/](/phase-1/credits-and-metering/). |
| Background Sync | Browser API (Workbox wrapper) that replays the upload outbox when connectivity returns. Chromium only; zero Safari support through 26.x, so iOS replays on `online`, `visibilitychange`, and app-open events. |
| bounding box | The pixel region on the receipt image a field was extracted from. Tapping a field zooms to its box (the Rossum tap-to-fix pattern) in the `review_items` stage. |
| BSP | Business Solution Provider, a Meta-authorised intermediary for the WhatsApp Business API. The route for WhatsApp approval nudges and receipt-in later. |
| burn rate | Credits consumed per day for a company. Drives the admin forecast ("out in ~N days") and the balance alerts at the 50/80/95/100% thresholds (configurable). |
| confidence threshold | The per-field extraction score above which a value auto-accepts: 0.80 (Azure convention). Below it the field is flagged; only merchant, date, and total always require explicit confirmation. |
| credit | The billing unit: 1 credit = 1 claim submitted into the approval workflow, with OCR for up to 5 receipt images, storage, approvals, payout files, and exports inside. Beyond 5 images: +1 credit per additional 5. Resubmission after `sent_back` is free. |
| credit pack | Prepaid credits, 12-month validity, non-refundable, consumed expiring-soonest first. Ladder: ₹499/50 up to ₹74,999/15,000 (₹9.98 down to ₹5.00 per credit). GST 18% extra. |
| de-skew | Rotating a captured page so text lines run horizontal. Runs server-side with perspective correction in the `crop_correct` stage. |
| DoA (Delegation of Authority) | The rupee-tiered approval grid: approver role × maximum amount (Concur pattern). One screen in the approval matrix; see [/phase-1/web/approval-engine/](/phase-1/web/approval-engine/). |
| DPDP Act | Digital Personal Data Protection Act 2023. We are typically a Data Processor; penalty ceiling ₹250 cr (Sec 8(5)). Rules notified 14 Nov 2025; full obligations phase in around May 2027 [govt, high]. |
| EXIF | Metadata embedded in photos (orientation, GPS, device). The `compress` stage re-encodes via canvas, which normalises orientation and strips sensitive EXIF before upload. |
| `getUserMedia` | The live camera-stream API behind the enhanced viewfinder. Progressive enhancement only: WebKit bug 252465 (frozen stream in installed iOS PWAs) reproduces through iOS 18.4.1, so iOS standalone defaults to file-input capture. |
| GST | Goods and Services Tax, India's unified indirect tax. Charged at 18% extra on all our prices; captured per line item (CGST/SGST or IGST split) on bills. |
| GSTIN | 15-character GST Identification Number. Validated by the GSTIN_FORMAT built-in rule (Luhn-mod-36 checksum) at extraction time. Example shape: `29ABCDE1234F1Z5`. |
| HEIC | Apple's default photo format. The file-input path requests `image/jpeg,image/png` via `accept`; the canvas re-encode guarantees JPEG reaches the server. |
| idempotency key | A caller-supplied token making a write safe to retry. Honored via `Idempotency-Key` on all POSTs and stored per record in the upload outbox. See [/spec/api/](/spec/api/). |
| IFSC | Indian Financial System Code, the 11-character bank-branch routing code (example shape: `HDFC0001234`). Drives NEFT/RTGS/IMPS routing in the [/reference/bank-files/](/reference/bank-files/) bulk-payment exports. |
| ImageCapture | The `ImageCapture.takePhoto()` API returning full-sensor stills from a stream. Chrome 59+; Safari/iOS 18.4+ (Mar 2025); fallback is a canvas grab at stream resolution. |
| IMPS | Immediate Payment Service, instant 24x7 rail, maximum ₹5 lakh per transaction. Payout-API costs sit around ₹1.75 to 5 per transaction [vendor pricing, medium]. |
| IndexedDB outbox | The client-side queue of pending uploads: blob, submission id, page index, idempotency key, attempts, last error. Makes capture offline-tolerant; distinct from the server-side soft-paywall queue. |
| ITC | Input Tax Credit, the GST a business offsets against output liability. Sec 17(5) blocks several T&E categories; the ITC_ELIGIBLE rule tags eligibility, informational for finance in Phase 1. |
| LTA | Leave Travel Allowance (Sec 10(5)/Rule 2B): domestic fare, 2 journeys per 4-year block, old regime only. ITC on LTC-type vacation travel is blocked under Sec 17(5)(b). |
| magic link | A signed single-use URL granting one scoped action: email approve/send-back buttons (amount-bounded), invites (7-day validity), and session continuity across the iOS install boundary. |
| maker-checker | The four-eyes control: the submitter (maker) can never be the approver (checker), enforced server-side. The most India-specific buying requirement, a first-class feature. |
| MSME / Udyam | Micro, Small and Medium Enterprises registered on the Udyam portal. The 45-day payment clock (Sec 43B(h)) is a Phase 2 vendor-payout differentiator, not in Phase 1 scope. |
| NEFT | National Electronic Funds Transfer, batch rail, no minimum or maximum. The default rail assumption for [/reference/bank-files/](/reference/bank-files/) bulk-payment exports. |
| `object-fit: cover` | The CSS rule for camera previews: crops to fill the box, never stretches. Half of the no-distortion rule; the other half is capturing onto a canvas sized exactly `videoWidth × videoHeight`. |
| paise | The canonical money unit: all API money is integer `amount_paise` with a `currency` field (INR default). Rupee decimals appear only at display time, never in stored or transmitted amounts. See [/spec/api/](/spec/api/). |
| PAN | Permanent Account Number, the 10-character income-tax identifier. Collected in Phase 2 vendor KYC alongside GSTIN, bank details, and Udyam; verification runs ~₹1 to 3 per check [indicative]. |
| Payment Aggregator (PA) | RBI-regulated entity that collects and settles funds between payers and merchants. Net worth ₹15 cr at application, ₹25 cr by year 3, mandatory escrow. We never trigger it: funds never touch our accounts. |
| Payment Gateway (PG) | Technology that routes payment transactions without handling funds. The PG-versus-PA line (no funds versus funds) is the side we stay on. |
| penny-drop | Verifying a bank account by sending a token credit and reading back the registered holder name. About ₹3 per verification [Setu, vendor pricing, high]. Gates every BeneficiaryAccount before it can receive a payout. |
| PEPM | Per Employee Per Month, the incumbent seat-pricing unit (Zoho ₹99/₹199 per user per month, vendor page). v2 rejects it: unlimited users free, submissions metered instead. |
| per-diem | Fixed daily allowance for travel. Tax-exempt only to the extent actually spent (Sec 10(14)/Rule 2BB); enforced by the PER_DIEM_CAP built-in rule (city-tier × grade). |
| perceptual hash | A fingerprint of image content that survives recompression and small crops. The capture-time layer of duplicate detection, before the submission-time date+amount warning. |
| perspective correction | Warping a trapezoid page photo into a flat rectangle. Server-side in v1, with a client manual 4-corner rescue editor; spec in [/spec/capture-pipeline/](/spec/capture-pipeline/). |
| PPI | Prepaid Payment Instrument (wallets, prepaid cards). Non-bank PPI net worth ₹5 cr rising to ₹15 cr. Issuing one is a permanent non-goal. |
| problem+json | RFC 7807 `application/problem+json`, the canonical error format for every `/api/v1` endpoint. |
| PWA | Progressive Web App: the installable, offline-capable employee capture app, delivered in stages from responsive web (Stage 0) to WebAPK (Stage 1) to TWA (Stage 2). See [/phase-1/capture/camera/](/phase-1/capture/camera/). |
| RCM | Reverse Charge Mechanism: the recipient pays GST instead of the supplier (GTA, legal services, unregistered suppliers). A Phase 2 vendor-tax concern; no RCM logic ships in Phase 1. |
| RLS | Row-Level Security in PostgreSQL 16: every tenant's rows are isolated by policy at the database layer, not just in application code. |
| RTGS | Real-Time Gross Settlement: minimum ₹2 lakh, no maximum. Rarely needed for employee reimbursements; relevant for large batch totals. |
| rule trace | The recorded evaluation of every rule firing on a claim: rule id, version, action taken (allow, flag, warn, cap, block, route), and input snapshot, persisted as an AuditEvent. |
| Section 17(5) | The CGST Act clause listing blocked ITC: food and beverages, outdoor catering, rent-a-cab, club/fitness, LTC vacation travel. Clause (b) blocks vacation travel benefits, not ordinary business travel. The core of the ITC_ELIGIBLE rule. |
| service worker | The background browser script that makes the PWA installable, caches the shell for offline use, and (on Chromium) runs Background Sync for the outbox. |
| snapshot-at-submission | A submitted claim carries the policy configuration and approval chain as they existed at submit time; rules themselves re-evaluate at each entry into `submitted`. Config edits never silently re-route in-flight claims; re-routing is an explicit admin action. |
| soft paywall | The balance-0 behaviour: capture and uploads continue (receipts go `queued`), submissions land in `awaiting_credits`, employees get a one-tap "remind your admin" nudge. Queue, never block; nothing is ever lost. |
| submission | The metered unit: one Claim entering the approval workflow. Manual-entry claims consume a credit too (the meter is the workflow, not the OCR); failed extraction never consumes extra. |
| Tally | Desktop accounting software with a claimed ~70 to 80% Indian SMB share [vendor-claimed, not independently audited]. Integrates via XML over HTTP on port 9000; a clean Tally JV export is a category gap the dossier treats as a wedge. |
| TDS | Tax Deducted at Source on vendor payments (194C, 194J, 194H families; rates change by financial year). Lives in [/phase-2/vendor-tax-engine/](/phase-2/vendor-tax-engine/). |
| TWA | Trusted Web Activity: the PWA wrapped via Bubblewrap into a Play Store listing ($25 one-time) when customer IT demands store presence. Stage 2 of the delivery ladder. |
| ULID | Lexicographically sortable 128-bit identifier. All API ids are prefixed ULIDs: `co_`, `clm_`, `li_`, `rcp_`, `cre_`, and the rest of the prefix table in [/spec/api/](/spec/api/). |
| UPI | Unified Payments Interface, instant account-to-account rail, ₹1 lakh standard per-transaction cap. A pack-purchase payment method and the prepaid-recharge mental model behind credits. |
| utility template | A Meta pre-approved, strictly transactional WhatsApp message (₹0.115 to 0.145 + 18% GST; free inside the 24h service window since Jul 2025). Marketing flavour risks recategorisation at ~6 to 7x the price. |
| UTR | Unique Transaction Reference, the identifier a bank returns per completed transfer. Matching UTRs from the bank's return file back to PayoutInstruction rows is how a PayoutBatch reaches `reconciled`. |
| variance-of-Laplacian | The blur metric in the `quality_gate` stage: low variance means a soft, unreadable image and triggers a retake prompt alongside a brightness-histogram check. |
| viewfinder | The live camera preview. v2 mandates a true-aspect-ratio viewfinder (the stretched-bill bug is always presentation code); the enhanced viewfinder adds edge overlay and auto-capture as Android-first progressive enhancement. |
| WebAPK | The real APK Android mints when a user installs a PWA from Chrome: home-screen icon, app-switcher presence, no store. The install prompt is deferred until after the first successful submission. |
| webhook | An HTTP callback we POST to a customer's WebhookEndpoint on events, signed HMAC-SHA256 in `X-Kharcha-Signature`. |

<p class="source-note">Definitions follow THESIS-V2 canonical contracts; regulatory and rail figures carry their original provenance. Full bibliography at [/reference/sources/](/reference/sources/).</p>

:::note[How to read provenance tags]
"govt, high" is a primary government figure. "vendor pricing" or "vendor-claimed" is a marketing or rate-card number, medium confidence at best. "our derivation" is a dossier estimate. Never relaunder a soft number into a hard fact when quoting these rows elsewhere.
:::
